[Troubleshooting](#troubleshooting)\n\n## Introduction\n\nAgentExtend is a decentralized AI inference platform that allows you to leverage external computers for AI processing tasks. With AgentExtend, you can:\n\n- Submit AI inference requests through your browser or command line\n- Pay for services using HIVE cryptocurrency tokens\n- Automatically upload results to Git repositories\n- Connect to a network of distributed AI nodes\n\n## Installation\n\n### System Requirements\n\n- Node.js 18 or higher\n- A modern web browser (Chrome, Firefox, Edge)\n- A Hive blockchain account with HIVE tokens\n- A Git account (GitHub, GitLab, or Bitbucket) for result uploads\n\n### Browser Extension Installation\n\n1. Download the latest release from the [releases page](https://github.com/your-org/agent-extend/releases)\n2. Extract the archive\n3. Open your browser and navigate to the extensions page:\n   - Chrome: `chrome://extensions`\n   - Firefox: `about:debugging`\n4. Enable "Developer mode"\n5. Click "Load unpacked" and select the extracted folder\n\n### CLI Tool Installation\n\n1. Install Node.js from [nodejs.org](https://nodejs.org/)\n2. Install AgentExtend globally:\n   ```\n   npm install -g agent-extend\n   ```\n\n## Getting Started\n\n### Setting up your Hive Wallet\n\n1. Create a Hive account at [https://signup.hive.io/](https://signup.hive.io/)\n2. Purchase HIVE tokens or receive them from another user\n3. Note your account name and private posting key\n\n### Configuring Git Integration\n\n1. Generate a personal access token from your Git provider:\n   - GitHub: Settings > Developer settings > Personal access tokens\n   - GitLab: Preferences > Access Tokens\n   - Bitbucket: Bitbucket settings > App passwords\n2. Save this token for use in AgentExtend configuration\n\n## Browser Extension Guide\n\n### Interface Overview\n\nThe AgentExtend browser extension provides a popup interface with the following sections:\n\n1. **Wallet Information**: Shows your HIVE token balance\n2. **Request Form**: Allows you to submit AI inference requests\n3. **Request History**: Displays your recent requests\n\n### Submitting Requests\n\n1. Click the AgentExtend icon in your browser toolbar\n2. Enter your prompt in the text area\n3. Select the AI model you want to use from the dropdown\n4. Adjust the bid amount if desired (default is 0.01 HIVE)\n5. Optionally enable Git integration and specify repository details\n6. Click "Submit Request"\n\n### Viewing Request Status\n\nYour recent requests will appear in the "Recent Requests" section. Click on any request to view its status and results.\n\n## CLI Tool Guide\n\n### Basic Commands\n\n- `agentextend init`: Initialize configuration\n- `agentextend request`: Submit an inference request\n- `agentextend status`: Check request status\n- `agentextend balance`: Check wallet balance\n- `agentextend nodes`: List available inference nodes\n\n### Submitting Requests\n\nTo submit a request with a simple prompt:\n\n```bash\nagentextend request --prompt "Write a poem about artificial intelligence"\n```\n\nTo submit a request with a prompt from a file:\n\n```bash\nagentextend request --prompt-file my-prompt.txt\n```\n\nTo specify a model and bid amount:\n\n```bash\nagentextend request --prompt "Analyze this data" --model gpt-4 --bid 0.05\n```\n\nTo upload results to Git:\n\n```bash\nagentextend request --prompt "Generate documentation" --git-repo myorg/myrepo --git-branch main\n```\n\n### Checking Status\n\n```bash\nagentextend status request-12345\n```\n\n## Configuration\n\n### Configuration File\n\nAgentExtend uses a JSON configuration file (`agentextend.config.json`) with the following options:\n\n```json\n{\n  "hiveNodeUrl": "https://api.hive.blog",\n  "gitProvider": "github",\n  "gitToken": "your-git-token",\n  "defaultBidAmount": 0.01,\n  "encryptionKey": "your-encryption-key"\n}\n```\n\n### Environment Variables\n\nYou can also set configuration options through environment variables:\n\n- `AGENTEXTEND_HIVE_NODE_URL`: Hive node URL\n- `AGENTEXTEND_GIT_PROVIDER`: Git provider (github, gitlab, bitbucket)\n- `AGENTEXTEND_GIT_TOKEN`: Git personal access token\n- `AGENTEXTEND_DEFAULT_BID_AMOUNT`: Default bid amount in HIVE tokens\n\n## Security\n\n### Encryption\n\nAll communication between clients and nodes is encrypted using AES-256. You can provide your own encryption key or let AgentExtend generate one.\n\n### Private Keys\n\nNever share your Hive private keys or Git personal access tokens. These should be kept secure and never shared.\n\n### Node Authentication\n\nNodes are authenticated through cryptographic keys. Only nodes with valid keys can participate in the network.\n\n## Troubleshooting\n\n### Common Issues\n\n1. **Insufficient Funds**: Make sure you have enough HIVE tokens in your account\n2. **Network Errors**: Check your internet connection\n3. **Git Upload Failures**: Verify your Git token has the correct permissions\n4. **Request Timeouts**: Try increasing your bid amount for faster processing\n\n### Getting Help\n\nIf you encounter issues not covered in this guide:\n\n1.
